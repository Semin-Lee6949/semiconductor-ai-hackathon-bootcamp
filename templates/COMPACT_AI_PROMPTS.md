# 강의 중 3회용 압축 프롬프트

## 1회 — 계획

```text
첨부한 README.md, AGENTS.md, PLAN.md와 데이터 열 설명만 사용하라.
파일을 수정하지 말고 문제, 주가설, 대안가설, 검증 순서와 완료 기준을 12줄 이내로 작성하라.
확인하지 못한 사실은 미확인으로 표시하라.
```

## 2회 — 구현

```text
승인된 PLAN.md의 현재 단계만 구현하라.
결측·이상치 감사, 핵심 그래프 1개, Holdout 평가에 필요한 최소 코드만 제시하라.
새 패키지는 추가하지 말고 PowerShell 실행 명령과 변경 파일을 함께 적어라.
```

## 3회 — 검수

```text
첨부한 git diff, 테스트 결과, 핵심 그래프만 검수하라.
오류 가능성, 반대 해석, Holdout 성능, 사람이 수정해야 할 부분을 구분하라.
확인된 내용만 이용해 README·HTML 보고서용 요약을 15줄 이내로 작성하라.
```
