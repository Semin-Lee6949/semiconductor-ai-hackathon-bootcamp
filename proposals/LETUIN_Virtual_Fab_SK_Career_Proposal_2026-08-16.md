# 2. 왜 지금 필요한가

## 채용은 학력표시보다 ‘증거’의 비중을 높이고 있다

SK하이닉스는 공개 채용 안내에서 A!SK를 자기소개서만으로 드러나지 않는 가치관·태도·직무역량을 입체적으로 보여주는 AI 화상 인터뷰로 설명하고 있다. 회사의 Talent hy-way 소개도 논리적 사고 과정, 문제해결 역량, 잠재력을 AI 기반 채용에서 확인한다고 밝힌다.

따라서 교육의 목표는 ‘AI를 사용했다’는 문장을 만들어 주는 것이 아니다. 지원자가 다음을 실제 산출물로 남기게 해야 한다.

1. 어떤 문제를 발견했는가
2. 어떤 전공지식을 연결했는가
3. AI에게 무엇을 맡기고 무엇을 직접 판단했는가
4. 데이터 품질을 어떻게 확인했는가
5. 어떤 가설을 어떤 실험으로 반증했는가
6. 실패와 한계를 어떻게 설명하는가

## 경험 접근성의 격차

실제 클린룸·장비·웨이퍼 실습은 대학과 경제력에 따라 접근성이 다르다. 본 과정은 실제 팹 경험을 대체한다고 주장하지 않는다. 대신 모든 학생에게 같은 합성 데이터와 사건을 주고 **데이터 기반 공정 문제해결 역량**을 비교 가능한 형태로 훈련한다.

## 세계적 선행사례와 국내 시장의 빈틈

- UC Davis는 클린룸 입장과 포토리소그래피를 게임으로 학습하는 브라우저 기반 교육 사례를 공개했다.
- Purdue는 vFabLab을 포함한 11~15시간 자율형 반도체 제조 입문 과정을 운영한다.
- 본 제안은 이들을 복제하지 않는다. **한국 취업준비생, 불량 원인 추론, 분석법의 비용·시간 선택, AI 판단 감사, 면접 포트폴리오 자동화**에 집중한다.

# 3. 교육상품의 핵심 구조

## Challenge Loop

**상황 발생 → 데이터 감사 → 경쟁 가설 → 실험계획 → 분석 툴 선택 → Holdout 검증 → 현업 조치 → STAR 면접자료**

## 첫 시나리오: 사라진 선폭의 비밀

- 상황: 평균 CD는 규격 안이지만 wafer edge 산포와 결함률이 증가
- 판단: 평균만 보고 진행할지, Lot을 보류하고 분포를 볼지 선택
- AI: 서버 Ollama가 초안을 생성하되 정답은 제공하지 않음
- 데이터: 결측·중복·단위·Tool 편중·위치별 분포 확인
- 실험: 대조군·요인·수준·반복·판정기준 설계
- 분석: Optical CD, SEM, TEM, EDX, XPS, I–V 중 정보가치로 선택
- 검증: 별도 Holdout과 재실험 결과로 한정 적용 여부 결정
- 결과: 본인의 의견과 한계를 포함한 9장 면접용 HTML 슬라이드 다운로드

## Three.js 기반 단계별 시각화

- Edge CD wafer
- 3D wafer map
- Screening DOE matrix
- Optical CD·SEM·I–V 분석 장비 bay
- Baseline–Holdout validation gate

## LLM 사용 원칙

- 실제 서버 로컬 Ollama 사용
- 검증 프레임은 코드가 고정하고 LLM 출력은 비판할 초안으로 분리
- 실제 회사 Recipe·Spec·로그·개인정보 입력 금지
- AI 답변의 채택·수정·기각 이유를 학습자가 기록

# 4. 4주 파일럿 커리큘럼

| 단계 | 라이브 | 핵심 내용 | 완료 증거 |

| 1주차 | 3시간 | 문제정의, 데이터 품질, Photo CD 시나리오 | 사건 판단·가설 3개 |

## 수준별 운영

### Foundation

- GitHub와 코딩 경험이 거의 없는 학생
- 템플릿 저장소, 단계형 질문, 지정 데이터 사용
- 목표: 한 시나리오 완주와 판단 근거 설명

### Builder

- Python 또는 바이브코딩 경험자
- 10개 데이터 중 하나를 선택해 Streamlit 또는 정적 웹앱 제작
- 목표: 기준모델–개선모델–Holdout 비교

### Advanced

- Coding Agent와 Git 경험자
- 새로운 결함 시나리오·상태전이·평가지표를 직접 확장
- 목표: 재사용 가능한 시뮬레이터와 3분 Pitch
