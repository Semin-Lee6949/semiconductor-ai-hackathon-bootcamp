# AI Usage

## 사용 범위

- 시나리오 흐름, 단계별 React/Three.js 장면, FastAPI 상태 전이, DeepSeek API 및 외부 AI 질문·답변 기록 흐름, Base64 HTML 슬라이드, 테스트 및 문서 초안에 AI를 활용했다.
- 최종 실행 결과는 Python API 테스트, TypeScript 빌드, Playwright 데스크톱·모바일 테스트로 검증했다.
- 시나리오 버전·seed·판단 순번을 세션과 Evidence trail에 기록하는 재현성 설계 및 테스트 초안에 AI를 활용했다.

## 사람의 검증 책임

- 공정 용어와 학습 목표는 강사가 검토한다.
- 시나리오의 수치와 판정 규칙은 교육용이며 실제 Recipe 또는 Spec으로 전용하지 않는다.
- LLM 제안은 정답으로 처리하지 않고 경쟁 가설·반증 가능성·누락 변수를 검토한다.
- DeepSeek 또는 외부 AI의 모델명·질문·답변과 사람의 수정·검증 판단을 함께 기록하며, AI 출력만으로 공정 결론을 확정하지 않는다.
- 공개 전 실제 회사정보, 개인정보, API 키가 포함되지 않았는지 확인한다.
