# Instructor Answer Keys — 수강생 공유 금지

- `answer_key.json`: A/B별 주요 신호, 교란·함정, 주입된 데이터 품질 문제
- 각 문제/A·B의 `holdout_labels.csv`: 평가용 목표값

정답은 특정 모델 하나가 아닙니다. 다음을 평가합니다.

1. 데이터 오류와 편중을 발견했는가?
2. 기준모델과 개선모델을 공정하게 비교했는가?
3. Holdout 분포 이동에서 성능 저하를 설명했는가?
4. 주가설 이외의 대안가설을 검토했는가?
5. 합성 데이터의 결과를 실제 공정 인과·Recipe로 과장하지 않았는가?
