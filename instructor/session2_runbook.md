# 2차 강의 강사용 Runbook — 150분

## 발표 전 자동·수동 점검

- Live URL HTTP 접근
- 모바일 폭에서 핵심 결과 확인
- 입력값 2개 이상 변경 가능
- 기준모델·평가 성능·오차 사례 표시
- `AI_USAGE.md`와 한계·추가 검증 존재
- 공개 금지 데이터·Key·개인정보 부재

## 1인 5분 운영

- 3분 발표: 문제 30초, 데이터·가설 30초, 데모 50초, 성능 30초, 인간 검증 20초, 효과·한계 20초
- 2분 질의: 기준모델, 평가 분리, 인과 제한, 실제 적용 안전장치, AI 오류 중 2개 질문
- URL 전환시간은 별도로 누적하지 않도록 발표순서표를 미리 연다.

## 공통 피드백 우선순위

1. 학습·평가 데이터 혼합
2. 실제로 움직이지 않는 UI
3. 기준모델 없는 성능 주장
4. 공정 상관관계의 인과 해석
5. AI가 만든 수치·설명의 무검증 사용
6. 과도한 기능과 불명확한 사용자 의사결정
