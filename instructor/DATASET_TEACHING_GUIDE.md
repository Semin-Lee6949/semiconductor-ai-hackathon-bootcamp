# 노이즈 데이터 지도 가이드

## 수업의 핵심 질문

“어떤 모델이 가장 높은 점수를 냈는가?”보다 다음을 먼저 묻습니다.

1. 이 숫자를 믿어도 되는가?
2. 특정 Lot·Tool·시간대가 결론을 지배하지 않는가?
3. 이상치는 공정 이상인가, 센서·단위·입력 오류인가?
4. 관찰된 관계를 설명하는 대안가설은 무엇인가?
5. 새로운 Tool·기간에서도 결론이 유지되는가?

## 의도적으로 넣은 문제

- Gaussian 측정 노이즈
- 열별 결측
- 완전 중복 행
- 10배 스케일 또는 섭씨↔켈빈 형태의 혼합 단위
- 극단 이상치
- 소량의 목표값·Class 라벨 오류
- Tool·Lot 표본 불균형
- 비선형·상호작용 효과
- 희귀 이상 Class
- 시간 Drift와 Holdout 분포 이동

## 권장 데이터 감사 순서

1. 행·열·자료형·단위·고유키
2. 결측률과 중복 `sample_id`
3. 분위수·IQR·물리적으로 의심스러운 범위
4. Tool·Lot·시간 구간별 표본 수
5. 목표값의 분포와 Class imbalance
6. 단변량 관계와 Interaction 후보
7. 시간순 또는 Tool 분리 Holdout

## 피드백 원칙

- 모든 이상치를 삭제한 학생보다 **왜 남기거나 제외했는지 근거를 기록한 학생**을 높게 평가합니다.
- 높은 학습점수보다 기준모델·Holdout·오차 사례를 정직하게 보여준 결과를 우선합니다.
- 정답표의 원인을 맞히는 것보다 교란 가능성을 구분하고 추가 측정·DOE를 제안하는 능력을 봅니다.
- 모델이 발견한 관계를 실제 공정 인과나 Recipe로 표현하면 감점합니다.

## 강사용 정답 사용법

`answer_keys/answer_key.json`의 `main_signal`은 발표 후 확인용이며 사전에 공개하지 않습니다. `confounder_or_trap`을 학생이 직접 찾지 못했더라도, 한계를 인지하고 추가 검증을 제안했다면 부분점수를 줍니다.
