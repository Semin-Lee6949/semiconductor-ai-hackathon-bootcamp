# 수강생용 합성 데이터팩

## 구성

- 10개 반도체 문제 × A/B = 20개 개인 데이터팩
- 각 팩의 `train.csv`: 목표변수 포함, 기본 800행과 의도적 중복행
- 각 팩의 `holdout_features.csv`: 목표변수를 숨긴 평가용 200행
- 강사용 `instructor/answer_keys/.../holdout_labels.csv`: 평가 정답

## 왜 일부러 지저분하게 만들었나

엔지니어의 일은 깨끗한 표에서 모델 버튼을 누르는 것이 아니라, 숫자 속에서 다음을 구분하는 것입니다.

- 실제 공정 신호와 측정 노이즈
- 공정 원인과 설비·Lot·시간 편중
- 선형 효과와 비선형 상호작용
- 이상 상태와 센서·단위 오류
- 학습 성능과 새로운 조건에서의 일반화

모든 데이터팩에는 결측, 중복, 이상치, 특정 열의 혼합 단위, 설비 편중, 측정 노이즈, 소량의 목표값 기록 오류, 평가 분포 이동이 포함됩니다. 이를 무조건 삭제하는 것이 아니라 발생 위치와 영향, 처리 전후 성능을 기록해야 합니다.

## 수강생이 먼저 할 일

1. 스키마·단위·범위를 검사한다.
2. 결측·중복·이상치를 수치로 보고한다.
3. Lot·Tool·시간순 표본 수와 목표값을 비교한다.
4. 기준모델을 만든다.
5. 가설과 대안가설을 각각 검증한다.
6. Holdout에는 학습 때 결정한 전처리만 적용한다.
7. 실제 공정 인과관계로 과장하지 않는다.

## 재생성

```bash
python tools/generate_datasets.py
python -m unittest discover -s tests -v
```
