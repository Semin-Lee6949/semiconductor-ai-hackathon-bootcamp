05

프로젝트 폴더 만들기

강의 저장소를 먼저 Fork하고 YOUR_GITHUB_ID를 바꿉니다.

cd $HOME\Documents
git clone https://github.com/YOUR_GITHUB_ID/semiconductor-ai-hackathon-bootcamp.git semiconductor-ai-project
cd semiconductor-ai-project
code .
06

필수 패키지 설치

프로젝트 폴더의 PowerShell에서 실행합니다.

py -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\python.exe -m pip install -r requirements-class.txt
07

GitHub Class Token 저장

  1. GitHub → Settings → Developer settings
  2. Personal access tokens → Fine-grained tokens
  3. 이름 SK-AI-Class, 만료 7일
  4. 개인 Fork 하나만 선택
  5. Contents: Read and write
Copy-Item .env.example .env
code .env
AI_PROVIDER=claude
GITHUB_CLASS_TOKEN=YOUR_FINE_GRAINED_TOKEN

AI_PROVIDER는 Claude=claude, GPT=openai, Gemini=gemini 중 하나를 씁니다.

토큰은 제출하지 않습니다. .env는 GitHub에 올리지 말고, 일반 git push는 브라우저 로그인을 우선 사용합니다.
