설치는 미리.
수업은 바로 실습.

Windows 기준 30~45분. PowerShell에서 아래 명령을 한 줄씩 실행합니다. 토큰·API 키·비밀번호는 누구에게도 보내지 않습니다.

00

프로젝트 폴더 만들기

cd $HOME\Documents
mkdir sk-ai-project
cd sk-ai-project
New-Item .env -ItemType File -Force
Set-Content .gitignore ".env`n.venv/`n__pycache__/"
01

GitHub 가입 · Class Token

GitHub 가입빈 저장소 만들기Token 발급
  1. 가입 후 이메일 인증
  2. 빈 저장소 sk-ai-project 생성
  3. 이름 SK-AI-Class, 만료 7일
  4. Only select repositories에서 방금 만든 저장소만 선택
  5. Contents: Read and write
cd $HOME\Documents\sk-ai-project
notepad .env
GITHUB_CLASS_TOKEN=여기에_발급받은_토큰
.env는 GitHub에 올리지 않습니다. 토큰 화면을 캡처하거나 공유하지 마세요.
02

Git 설치 · 사용자 설정

PowerShell을 다시 연 뒤 실행합니다.

git config --global user.name "본인 영문 이름"
git config --global user.email "GitHub 가입 이메일"
git --version
git config --global --list
