# 1강 문제발견 질문지 — 숫자에서 엔지니어의 결정으로

> 좋은 프로젝트는 모델 이름이 아니라 **누가, 어떤 신호를 보고, 무엇을 결정해야 하는가**에서 시작합니다.

이 질문지는 수업 전 10분 동안 1차로 작성하고, 1강 마지막 4분에 데이터 감사 결과를 반영해 다시 씁니다. 완벽한 답보다 검증 가능한 작은 문제 하나를 남기는 것이 목표입니다.

## 사용 원칙

- 실제 회사 데이터·공정 Spec·장비 로그·고객정보를 적지 않습니다.
- 장비명·Recipe·수율 수치는 일반화하거나 교육용 합성값으로 바꿉니다.
- AI가 제안한 물리식과 해석은 전공 교재·논문·공식 문서로 확인합니다.
- 상관관계를 인과관계로 표현하지 않고 대안 설명을 최소 1개 적습니다.

## A. 문제를 발견하는 8개 질문

각 질문에 한 문장으로 답합니다.

1. **누가 어려움을 겪는가?**
   - 예: 설비 엔지니어, 공정 엔지니어, 품질 엔지니어, 투자 의사결정자
2. **그 사람은 반복적으로 무엇을 보고 있는가?**
   - 예: 시계열 Log, 계측 결과, 검사 이미지, 시장 가격
3. **평소와 달라졌다는 것을 어떤 신호로 알아차리는가?**
4. **이상 신호를 놓치면 어떤 비용이나 위험이 생기는가?**
5. **반대로 알람이 너무 많으면 어떤 문제가 생기는가?**
6. **신호를 본 뒤 실제로 선택해야 하는 행동은 무엇인가?**
   - 계속 진행 / Hold / 점검 / 재측정 / 조건 변경 / 전문가 호출
7. **현재 판단에서 가장 불확실하거나 사람마다 다른 부분은 무엇인가?**
8. **7일 안에 어떤 작은 화면이나 리포트로 판단을 도울 수 있는가?**

## B. 문제를 전공과 연결한다

| 질문 | 내 답 |
|---|---|
| 관련 전공과목은 무엇인가? |  |
| 그 과목에서 설명하는 핵심 현상은 무엇인가? |  |
| 입력과 출력의 방향을 제한하는 물리·화학·회로·경제 원리는 무엇인가? |  |
| 참고할 Governing equation 또는 제약식 후보는 무엇인가? |  |
| 식의 출처는 어디에서 확인할 것인가? |  |
| 식이 설명하지 못하는 현장 변수는 무엇인가? |  |

`Governing equation`은 AI가 그럴듯하게 만드는 수식이 아닙니다. AI에는 후보 식, 변수 정의, 적용 조건을 찾게 하고 사람은 전공 교재·논문·공식 자료로 확인합니다. 정확한 방정식이 없는 문제라면 보존법칙, 단조성, 허용범위, 시간 순서 같은 **도메인 제약**을 사용합니다.

## D. 상관관계와 인과관계를 분리한다

1. 예상하는 상관관계는 무엇인가?
2. 원인이라고 주장하려면 어떤 시간 순서가 필요한가?
3. 두 변수를 함께 움직이는 제3의 요인은 무엇인가?
4. 그룹별로 나누면 관계가 사라지거나 반전될 수 있는가?
5. 개입 실험이 어렵다면 어떤 대안 가설을 비교할 것인가?
6. 현재 데이터로 말할 수 없는 것은 무엇인가?

### 도메인 밖 비교 예시 — 미국 주식과 한국 주식

미국 지수와 다음 날 한국 지수의 상관관계가 높아도 미국 시장이 한국 시장을 직접 움직였다고 단정할 수 없습니다. 시간대, 환율, 금리, 글로벌 위험선호, 반도체 업황, 자기상관과 사건일 편중을 함께 확인해야 합니다. 이 예시는 **변수가 많아질수록 해석 규칙이 중요하다**는 것을 보여주기 위한 것이며 투자 예측 과제가 아닙니다.

## E. AI가 할 일과 사람이 검증할 일을 나눈다

### AI가 도울 일

- Log 스키마·결측·중복·단위 감사
- 변화점·이상 패턴 후보 탐색
- 변수 관계 시각화와 기준모델 코드 초안
- Governing equation·관련 문헌 후보 검색
- 대안 가설과 반론 생성
- 재현 가능한 리포트·웹 화면 초안

### 사람이 결정할 일

- 문제가 실제 사용자 결정과 연결되는지 확인
- 물리식·변수 정의·데이터 누수 검증
- 알람 임계값과 오탐·미탐 비용 결정
- 상관관계를 인과로 과장하지 않는 해석
- 실제 적용 전 필요한 안전·장비·공정 검증

## F. 완성 예시 — Photo PR 공정 Margin 탐구

```text
사용자: Photo 공정 엔지니어
문제: PR tone·코팅 두께·Dose·Focus·PEB·현상조건이 함께 바뀔 때
      CD와 결함 위험을 모두 고려한 작은 DOE 조건을 고르기 어렵다.
전공 연결: 포토리소그래피, 광학, 고분자·현상 원리, 통계와 DOE
입력 후보: PR tone, retained pattern source, 코팅 두께, 정규화 Dose,
          Focus, PEB 온도, 현상시간, Tool·Field 위치
출력 후보: CD, CDU, LER, Scum, Collapse, Defect risk, Spec pass
AI 역할: PR tone별 관계와 두께·PEB·현상의 상호작용 후보를 시각화한다.
사람 검증: 재료계·mask/feature tone·광학계·Tool·Field·계측 편중을 검토한다.
의사결정: 먼저 검증할 작은 DOE 조건과 추가 계측 항목을 고른다.
위험 KPI: CD 평균은 맞지만 Scum·Collapse 위험을 놓치는 비율
주의: 실제 PR 재료와 Recipe가 아닌 교육용 합성 데이터만 사용한다.
```

이 예시의 목적은 CD 하나만 예측하는 것이 아닙니다. Positive·Negative PR을 구분하고, CD·CDU·LER와 Scum·Collapse의 trade-off를 함께 보며 실제 적용 전 필요한 작은 DOE를 제안하는 것입니다.

## H. 1강 종료 제출

1. 위 한 문장 문제정의 1개
2. 후보 주제 2개
3. 각 후보의 사용자 결정 1개
4. Governing equation·도메인 제약 후보 1개
5. 예상 상관관계와 대안 설명 각 1개
6. 실제 회사정보를 포함하지 않았다는 확인

최종 주제는 데이터 감사 후 확정합니다. 문제를 설명할 수 없거나 사용자 결정이 없으면 모델을 선택하지 않습니다.
